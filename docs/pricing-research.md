## Revised Pricing for This Product

Our data is a **taxonomy reference** — how each state defines Medicaid specialties, what categories they use, and how they map to NUCC codes. The raw data is public; the value is in extraction, verification, and structuring.

### Standalone Data Product

| Package | Price |
|---------|-------|
| Single state (CSV + methodology doc) | $200–$500 |
| Multi-state bundle (10+ states) | $2K–$5K |

**Rationale:** CarePrecise sells 9M provider records for $600–$3,600. Our 50–130 specialty rows per state, even verified, don't justify $5K+ as standalone data.

### Consulting Deliverable

| Engagement | Value |
|------------|-------|
| Consulting rate (network adequacy) | $150–$250/hr |
| Research time saved per state | ~20–40 hours |
| Data bundled with consulting | $3K–$10K per state |

**Rationale:** The data saves 20–40 hours of primary-source research per state. At $150–$250/hr, that's $3K–$10K in time savings when bundled into a consulting engagement.

### Embedded in Quest Analytics Platform

| Tier | Price |
|------|-------|
| Data layer per state | $5K–$15K |
| Full platform deal | $100K+ |

**Rationale:** Highest-value path. Embedded as a value-add tier in an existing $100K+ platform subscription. Justifies premium pricing as part of a larger deal.

## Previous Estimates vs Reality

| Previous Claim | Reality |
|----------------|---------|
| "$5K–$15K per state package" | Overstated for standalone data. Valid only as consulting deliverable or platform add-on. |
| "$35K–$105K from 7 states" | Speculative — no buyer identified, no LOI, no pricing validated. |
| "$50K+ subscription API at 20–30 states" | Plausible but unproven. More realistic: $10K–$25K/yr for a narrow Medicaid-specialty API. |
| README: "$10K–$50K/year subscription" | Overstated. Adjusted to $10K–$25K/yr based on comparable narrow-reference products. |
