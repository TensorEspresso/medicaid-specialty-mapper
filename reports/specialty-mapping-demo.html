AI-Powered Provider Specialty Mapping

Automated classification of free-text specialty labels to standardized Medicaid codes

Capability Overview

The system ingests arbitrary provider specialty input — abbreviations, colloquial labels, partial names — and resolves them to authoritative state Medicaid specialty categories backed by NUCC taxonomy codes, with confidence scoring and explicit flagging of ambiguous mappings.

Architecture

1
Input Ingestion — Accepts specialty labels in any format: abbreviations (Ortho, ENT, Peds Card), colloquial terms (Allergies, Infectious), full names, or mixed batches. No preprocessing or normalization required.
2
NUCC Taxonomy Resolution — Each input label is matched against the full NUCC taxonomy dataset (884 codes, v25.1) using semantic search across classification, specialization, and definition fields. The system resolves abbreviations to their canonical specialty (e.g., Peds Card → Pediatric Cardiology) and identifies the most specific NUCC code (preferring Specialization over Classification over Grouping).
3
State Crosswalk Resolution — The resolved NUCC code is mapped to the target state's Medicaid specialty category. Two lookup methods are used: (a) Official crosswalk — state-published NUCC-to-specialty mapping where available (e.g., FL's Taxonomy Master List, NC's Provider Permission Matrix); (b) Name-matching fallback — direct matching of NUCC classification/specialization names against state specialty catalog entries when no official crosswalk exists.
4
Edge Case Handling — Three special cases are detected and handled explicitly: Subspecialty-to-parent (e.g., Pediatric Cardiology → Cardiology when the state has no pediatric subspecialty), Dual-mapping (e.g., Pediatric Hematology-Oncology → both Hematology and Oncology), and No-match flagging (e.g., Allergy/Immunology when the state has no corresponding category). Each is scored down appropriately and annotated with reasoning.
5
Confidence Scoring & Output — Each mapping receives a 0.0–1.0 confidence score based on match precision. The output includes the original input, resolved NUCC code, state Medicaid category, tier assignment, confidence score, and mapping rationale. Items below 0.50 are flagged for human review rather than auto-assigned.

Data Lineage

Every mapping traces a verifiable chain: Input label → NUCC taxonomy code (with definition from v25.1) → State Medicaid specialty category (with source document reference). No step is opaque — each link in the chain is auditable against the underlying reference data.

Key State Differences

FL has dedicated categories CA lacks

  • Allergy — FL has a distinct Allergy specialist category (1:20,000 ratio); CA does not — flagged for human review
  • Cardiology (Pediatric) — FL has a dedicated peds cardiology tier (1:16,667 ratio); CA collapses to parent Cardiology
  • Infectious Diseases — FL lists explicitly (1:6,250 ratio); CA bundles with HIV/AIDS

Classification differences

  • OBGYN — FL classifies as Specialist only; CA assigns dual Primary Care + Specialist role
  • Peds Onc — Both collapse to parent Oncology; CA dual-maps to Hematology as well (0.70) vs FL single-map (0.75)
